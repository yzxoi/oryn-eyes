# Oryn Eyes

Oryn Eyes is a stateless support service, not a fork of the Synergy product. Use only the pinned public harness/runtime-local/util/link-protocol packages. Keep GitHub credentials and all publication outside the model worker. Never add shell, edit, merge, close, or arbitrary repository access to the support agent.

Run `bun run check` for changes and `bun run smoke` for Core boundary changes after installing Core. Tests live in `test/`. Preserve tests for image bytes, source evidence, cancellation, authentication, idempotent publication, and bounded queues. Do not store user conversations, screenshots, provider keys, or diagnostic payloads in Git. Keep runtime data temporary and logs bounded and redacted.

Changes to behavior need README and a decision note. Commit only task-owned paths with a conventional subject and `Co-authored-by: synergy-agent <299070056+synergy-agent@users.noreply.github.com>`.
